# 🚗 Car Sales Analysis Dashboard

## 📊 About the Project

This project is a **Power BI dashboard** created to analyze car sales data and understand sales performance, pricing, and vehicle characteristics.

The dashboard helps answer questions such as:

- Which car models have the highest sales?
- Which regions have the highest sales volume?
- Which fuel types and transmissions are most common?
- How does car price relate to sales volume?
- Does mileage affect car price?
- Does engine size relate to price or sales?

## 📁 Dataset

The dataset contains **50,000 car records** with information about:

- Model
- Year
- Region
- Color
- Fuel Type
- Transmission
- Engine Size
- Mileage
- Price
- Sales Volume
- Sales Classification
